# Restricted decoder-raster candidate evidence — 2026-10-02

This is native arm64 libmpv candidate evidence, separate from shipping app tests.
The provider patch in ../../dependency-patches passed source apply and six C
syntax checks (arm64 + x86_64). Its three changed C units were compiled into an
isolated copy of the arm64 retained scratch objects, then linked into a C client.
The retained historical build was not edited. Source, compiler, patched source,
link command, harness, fixture, and linked-client identities are recorded in the
JSON receipts. No executable, objects, or binary fixture are retained here.

`native-harness.c` checks independently numbered 16x16 RGB grids generated by
`generate-grid.py` and encoded losslessly as FFV1 by ffmpeg. It requires exact expected
PTS 0, seek 1, and frame-step 1.2, independently checks every BGRA pixel, and
asserts freshness equality, node types/tags/proofs/track/geometry/byte bounds. All
state mutations check API success; each guard restoration requires a successful
new capture before the next guard is exercised. Each named case below exited 0:

- `runtime-enabled.jsonl`: opt-in with decoder queue disabled, captures + guards.
- `runtime-queue.jsonl`: opt-in with default decoder queue, captures + guards.
- `runtime-default.jsonl`: provider option omitted; capture unavailable.
- `runtime-no.jsonl`: provider explicitly disabled; capture unavailable.
- `runtime-square-rotated.mp4.jsonl`: actual 90-degree container display matrix
  on a square RGB fixture; capture unavailable. Generator verifies the matrix.
- `runtime-anamorphic.mkv.jsonl`: actual 2:1 sample aspect; capture unavailable.
  Generator verifies the sample aspect metadata.

Logs for each run are compressed separately. `runtime-receipt.json` binds binary
and input hashes from the temporary runtime environment; these paths are retained
historical paths, not portable build instructions. `rebuild-native-objects.py`
and `link-native-harness.py` retain the actual object rebuild and link procedure.
`retained-mpv-link-command.txt` is the retained link command whose main entry
object was replaced by the harness object. `harness-link-command.json` records
the exact final argument vector. Use the main provider engineering document for
portable verification and remaining release gates.

No x86_64 runtime, hardware decoder, rotated/reflected or anamorphic positive
case, sustained memory workload, sanitizer, or app integration is established.
The bounded ring can fail closed when a presented frame has been evicted.
